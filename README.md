A one-line roast of a daily gadget, written as a program. Running `main.py` writes a single original roast — my robot vacuum, which has mapped every inch of my apartment yet still hunts down the one cable I actually need and eats it — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program is deterministic: every run writes the exact same line (104 characters, no trailing newline).
